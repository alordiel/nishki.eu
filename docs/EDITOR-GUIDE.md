# Editor guide — admin.nishki.eu

**Nothing changes on the live site until you click _Publish site_** (top right). Publishing takes 1–3 minutes; the text next to the button shows when the site was last updated. Clicking again while it runs is fine — your latest changes will be included.

## Languages
Switch **Български / English** at the top of any page, project or setting. Photos and layout are shared; only texts differ. An empty English text falls back to Bulgarian.

## Projects (weddings)
*Content → Projects → Create new*
1. **Title** (names), venue, location, season, date (used for ordering), **cover** photo, short **excerpt**.
2. **Slug** — the web address, e.g. `maria-ivan` → nishki.eu/gallery/maria-ivan/.
3. **Gallery**: add blocks in any order — *Collage* (select or drag in many photos at once; drag to reorder), *Lead* (a paragraph of text between collages), *Image banner* (one wide photo).
4. **Publish** the project (bottom right), then **Publish site**.

To show a project under "Любими проекти" on the home page: *Pages → Начало → Любими проекти block → Projects*. The gallery page lists all published projects automatically.

## Pages
Each page is a stack of blocks (hero, text, photos, FAQ, …). Add, remove or drag blocks to reorder. Save as draft while working; **Publish** the page when ready.

## Photos
Upload JPG/PNG/WebP up to 40 MB — they are resized automatically. Always fill in **Alt** (a short description; helps Google and visually impaired visitors). Set the **focal point** if a crop cuts off faces.

## Enquiries
*Inbox → Submissions*. New enquiries also arrive by email — reply directly to that email. Set status to *Read* / *Archived* to keep the list tidy. Enquiries are deleted automatically after 12 months.
